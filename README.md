# Eagle Creek Golf Club - Web UI

A modern, fully responsive landing page interface designed for a golf club. This project showcases dynamic UI components including a weather widget, property booking cards, course highlights, and nearby attractions, all built with clean, responsive web design principles.

**Live Demo:** [View Site on Netlify](https://htmlcssw3.netlify.app/)

---

## 🎯 Features

* **Responsive Weather Widget:** Displays a daily forecast strip and a breakdown of seasonal weather patterns with custom SVG icons. Adapts from a grid on desktop to a swipeable layout with large current temperatures on mobile.
* **Stay & Play Packages:** Features interactive property cards with image badges, rating displays, and distinct "Stay" vs. "Play" pricing tables.
* **Course Highlights:** A multi-column grid layout detailing course specs, yardage, and features, which gracefully collapses into a touch-friendly horizontal carousel on mobile devices.
* **Nearby Courses Explorer:** Clean, image-led cards displaying distance, yardage, par stats, and notable history for neighboring golf clubs.
* **Fully Responsive:** Meticulously styled across Desktop, Tablet, and Mobile breakpoints using CSS media queries.

## 🛠️ Built With

* **HTML5:** Semantic markup and structure.
* **CSS3:** Custom styling utilizing CSS Flexbox and CSS Grid for complex layouts.
* **Inline SVGs:** Scalable, lightweight icons styled directly with CSS (no external icon libraries required).
* **Vanilla Implementation:** Zero external frameworks or libraries—just pure HTML and CSS.

📱 Responsive Breakpoints
This project uses a mobile-first/adaptive approach with the following key breakpoints:

Desktop: > 1024px (Full grid layouts, expansive map views)

Tablet: 768px - 1024px (Adapted 2-column grids)

Mobile: < 768px (Stacked layouts, horizontal scroll carousels, hidden desktop pagination)
